`rubber_reference_20260927.json.gz.b64` — сжатый JSON-архив фактического
запуска `/api/run` на сервере демо и последующей проверки `/api/review`.
Хранит конфигурацию и запрос, все полученные события потока, полное состояние
пяти агентов, структурированную проверку контрольной рецептуры и ответ судьи.

MAPE текущего запуска и вердикт судьи.

оцифрованных точках. Полученная MAPE по четырём свойствам — 3,2123 %.
