# Rubber-property MAS prototype

Прототип использует `fedotmas.MAS` с динамическим мастер-оркестратором. На вход
подаётся готовый рецепт, а результатом служат прогнозы четырёх свойств. Система не
генерирует и не оптимизирует состав.

## Архитектура

```text
готовый рецепт
      |
      v
rubber_property_master
      |
      +--> predict_rubber_properties (MCP, открытые данные)
      |
      +--> formulation_validator
      +--> rubber_chemistry_reviewer
      +--> prediction_auditor
      |
      v
property_prediction
```

Мастер передаёт MCP-инструменту все ингредиенты без изменений. Внутри инструмента
проверяются баланс NR/SBR, фиксированные условия открытой серии и границы её
составов. Затем мастер отдаёт численный результат трём агентам и формирует ответ с
рецептом, прогнозами, неопределённостью и планом лабораторной проверки.

## Данные

Используется открытая серия SBR-1502 / NR SMR-20 / N220 из работы J. K. Oleiwi,
M. S. Hamza, N. A. Nassir, DOI
[10.5281/zenodo.3838695](https://doi.org/10.5281/zenodo.3838695), CC BY 4.0.
Двадцать значений оцифрованы из графиков и поддерживают только:

- теплопроводность;
- набухание в моторном масле после 1006 часов;
- набухание в воде после 1006 часов;
- удельный вес.

Эти данные подходят для исследовательского скрининга и требуют лабораторной
валидации точного рецепта и режима процесса.

## Запуск

Полный запрос с исходным составом находится в
[mas_input_request.md](mas_input_request.md); `run_mas.py` читает этот файл.

```sh
uv run python experiments/rubber_recipe_mas/run_mas.py --model openrouter/qwen/qwen3-32b
```

Для API-модели нужен ключ провайдера. Локально можно использовать `--model host/gpt-5.6-terra`
после `codex login`. Запуск CLI выполняет реальные вызовы выбранной модели.

GUI запускается командой `uv run python gui/run.py`, адрес — <http://localhost:4173/>.
В публичном режиме доступны только API-модели.
