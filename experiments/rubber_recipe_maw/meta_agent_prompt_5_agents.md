# Промпт для meta-agent FEDOT.MAS

Создай MAW для оценки свойств заданного рецепта протекторной резины. Система не
генерирует и не изменяет рецептуру. Она проверяет корректность входного состава,
получает единственный численный прогноз через MCP-инструмент
`rubber-recipe-predictor`, анализирует применимость открытых данных, независимо
проверяет полноту и непротиворечивость численного результата и возвращает единый
итог `property_prediction`: исходный рецепт, предсказанные свойства с диапазонами
и единицами, ограничения и минимальные лабораторные проверки. Только агент,
выполняющий численный прогноз, должен иметь MCP-инструмент. Финальный результат
не должен содержать выводов о безопасности, сертификации или промышленной
готовности шины.

Требование к размеру команды: создай ровно пять содержательных агентов. Целевой
состав — три предметные роли, отдельный агент-сборщик и отдельный
агент-проверяющий. Каждая роль должна иметь самостоятельную ответственность и
уникальный результат; не добавляй фиктивных агентов, которые только повторяют
чужую работу. Если роли зависят друг от друга, отрази зависимость в графе,
сохранив общее число агентов равным пяти.

Имена агентов, их инструкции и весь текст конфигурации должны быть на русском
языке. Имена агентов пиши строчными буквами через подчёркивание.
