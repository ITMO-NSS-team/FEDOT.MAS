# Задача для meta-agent FEDOT.MAS

Создай мультиагентную систему с паттерном MAS и мастер-оркестратором для
аудита технологической карты строительной работы.

Система получает идентификатор ТТК и правило выявления отклонений. Мастер
поручает профильным агентам извлечь количественные нормы со ссылками на
конкретные строки карты, сопоставить работу с историческими записями по
нормализованному полю `granular_name` и программно проверить фактическую
выработку через MCP-инструмент `technology-card-audit`.

Роли: мастер-оркестратор; экстрактор нормативов ТТК; аналитик исторической
производительности; аудитор доказательств. Итог мастер возвращает в поле
`technology_card_audit`.

В результате покажи извлечённые нормы, проверку их внутренней
согласованности, число просмотренных записей и таблицу нарушений с
обязательными ссылками на карту. Не генерируй график работ, не меняй карту и
не придумывай отсутствующие нормы. Демонстрационные данные явно отдели от
реальных данных STAIRS/SAMPO.
